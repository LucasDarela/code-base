## Logs

- Logs estruturados (JSON), nunca strings concatenadas.
- Campos obrigatórios: `timestamp`, `level`, `event`, `request_id`; `user_id` quando houver usuário.
- `event` em `snake_case`, no formato `<entidade>_<ação no passado>` (ex.: `order_created`, `payment_failed`).
- **Nunca** logar: senhas, tokens, chaves, documentos pessoais, dados de cartão, corpo completo de requisições. Detalhes em `SECURITY.md`.

| Nível | Quando usar |
| ----- | ----------- |
| `error` | Falha que exige ação humana ou afetou a pessoa usuária |
| `warn` | Situação anormal tratada (retry, fallback) |
| `info` | Eventos de negócio relevantes |
| `debug` | Diagnóstico local; desligado em produção |
